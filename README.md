# Budget Analysis with SQL & Python

A complete data analysis project combining SQL and Python to explore and visualize financial data across departments.

## 📁 Project Structure

- `SQL_Queries.sql` – SQL queries for extracting and aggregating transactional data
- `Transactions_Data.xlsx` – Raw dataset used in the analysis
- `Data_Analysis_Notebook.ipynb` – Jupyter Notebook with Pandas and Matplotlib visualizations
- `Project_Overview.pdf` – Summary presentation explaining the approach and results

## 🛠 Tools & Technologies
- SQL
- Python (Pandas, Matplotlib)
- Excel

## 🎯 Key Objectives
- Analyze budget execution by department
- Identify actual vs planned budget discrepancies
- Visualize performance metrics across time and categories
